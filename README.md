## Getting Started

### Installation

Clone the repo

```sh
git clone https://github.com/Nhed1/assets-tractian.git
```

Install NPM packages

```sh
npm install
```

Run the project

```sh
npm run dev
```

Run the tests

```sh
npm run test:ui
```
