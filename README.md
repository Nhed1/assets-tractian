<strong>What I would improve with more time:</strong>

<strong> Increase test coverage:</strong> I would expand the test suite to cover more parts of the codebase, including edge cases, ensuring higher reliability.

<strong>Improve API handling and user feedback:</strong> Instead of just using loading icons, I would enhance the user experience by implementing skeleton screens during data loading. This would provide a smoother, more modern feel to the UI. Additionally, I would handle errors more gracefully, incorporating retry mechanisms and refetch buttons for better error recovery and user control.

<strong>Optimize performance:</strong> With more time, I would work on optimizing the performance of the application, implementing techniques like code-splitting, lazy loading for components.

## Getting Started

### Installation

Clone the repo

```sh
git clone https://github.com/Nhed1/assets-tractian.git
```

Install NPM packages

```sh
npm install
```

Run the project

```sh
npm run dev
```

Run the tests

```sh
npm run test:ui
```
